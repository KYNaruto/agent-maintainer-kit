# Maintainers

## Primary Maintainer

- KYNaruto: project direction, implementation, issue triage, pull-request review, documentation, release preparation, and security response.

## Maintainer Responsibilities

The primary maintainer is responsible for:

- Reviewing issues and pull requests.
- Keeping CI, tests, examples, and documentation current.
- Reviewing agent-generated reports before merge or release.
- Maintaining command-risk policies and security guidance.
- Preparing changelog entries, release checklists, tags, and GitHub Releases.

## Decision Process

Small changes are accepted after tests and maintainer review. Larger behavior or policy changes should be discussed in an issue before implementation.

Agent-generated output is advisory. Final merge, triage, security, and release decisions remain with a human maintainer.

## Becoming a Maintainer

Regular contributors may be invited to help maintain the project after demonstrating sustained, constructive participation in issues, reviews, documentation, or implementation.

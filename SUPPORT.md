# Support

## Questions and Usage Help

Open a GitHub issue with a concise description, the command you ran, and relevant environment details.

## Bug Reports

Use the bug report issue template and include:

- Reproduction steps.
- Python and operating-system versions.
- Relevant transcript or config snippets with secrets removed.
- Full command output or traceback.

## Security Reports

Follow [SECURITY.md](SECURITY.md). Do not publish sensitive exploit details, credentials, or tokens in a public issue.

## Scope

Agent Maintainer Kit is maintained as an open-source project. Support is best effort, and compatibility requests are prioritized based on maintainer capacity and value to OSS maintenance workflows.
